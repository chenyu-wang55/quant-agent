# 明确股票池的日频研究与回测

2026-10-13，所有者选择先完成免费数据、明确股票池、日频技术研究版本，并披露覆盖限制。本工具与既有SP500多因子生产链路分开，输出不进入订单、审批、自动执行或paper验收。

## 运行入口

免费数据入口采用Twelve Data Basic。官方说明[免费股票数据](https://twelvedata.com/stocks)及[历史日线交付](https://support.twelvedata.com/en/articles/9935903-us-equities-market-data)：历史/EOD数据在收盘后的下一个交易日纽约时区零点之后可用。HTTP认证使用官方推荐的 `Authorization: apikey ...` 请求头，参见[官方文档](https://twelvedata.com/docs/mcp)。不使用收费端点，不把密钥放进URL、命令行参数、报告或原始数据归档。

所有者从自己的免费账户取得密钥，在项目 `quant-agent/.env.local` 加入：

```dotenv
TWELVE_DATA_API_KEY=你的个人免费密钥
```

不要将密钥发到聊天或GitHub。这个文件已有Git忽略规则。程序只读取这一字段，不执行shell展开、不加载同文件中的交易开关；官方demo不接受为真实研究输入。没有个人密钥时明确blocked，不伪造完成结果。

```bash
.venv/bin/python scripts/run_price_research.py
```

默认冻结配置为 `docs/manifests/price_research_v1.json`，输出 `artifacts/price_research/`，其中包括请求缓存、按内容指纹保存的不可变原始数据、冻结配置与独立run目录。默认先收齐股票池和SPY的全部交易日，缺失任何日期、错误时区、不同标的、无效OHLC或部分响应均拒绝。有效已取得的请求可复用缓存；失败不会生成虚假的最新候选。

账户共享SQLite本地限额为7次/61秒、200次/UTC日，均低于Basic公开额度。每次请求在发送前预留；跨进程共享同一个quota文件。401、403、429、5xx和厂商业务错误停止本次采集，不改身份、不自动升级套餐。账户在其他应用中使用的额度仍可能导致源站限流。

已取得的完整数据可完全离线重放：

```bash
.venv/bin/python scripts/run_price_research.py --dataset artifacts/price_research/datasets/<SHA-256>
```

原始文件SHA-256、大小与manifest一并核对。源数据或配置在执行期间变化、报告ID与内容不一致时拒绝。新数据/配置得到新run，不覆盖历史run。

## 冻结研究口径

- 股票池为AAPL、MSFT、AMZN、GOOGL、META、NVDA、AVGO、ORCL、AMD、CRM、JPM、BAC、V、MA、UNH、JNJ、XOM、CVX、PG、COST，共20个当前明确标的；SPY为比较基准。该名单于2026-10-13选定，有选择与幸存者偏差，不代表历史SP500/NASDAQ100。
- 2015年起收取预热行情；历史模拟2016-01-04至2025-12-31，开发段2016–2023、验证段2024、末尾时间段2025。这里只评估提前固定的规则，没有参数搜索、模型拟合或收益驱动调参；这些时间段不是已完成机构级OOS验收的声明。
- 最近一期请求截至2026-10-12完整日线，决策截止2026-10-13纽约零点。价格不齐时拒绝，不把老快照当作这一期结果。之后的研究需用新的配置版本更新截止日；最近结果接口不是自动行情刷新服务。
- SPY收盘不低于200日均线才允许风险仓位。单股需收盘>50日均线>200日均线、63交易日超额动量为正、20日年化波动不高于60%。排序规则分为0.6×63日超额动量+0.4×20日动量，分数不是胜率。
- 每5个交易日重新分配，最多8个标的，每标的10%，板块30%，总投入80%；剩余为零利息现金。板块标签是冻结的研究假设，不是历史PIT行业资料。仓位限制应用于开盘分配，随后价格变化可能使权重漂移。
- 决策只读当时已发布的日线，使用决策后同日9:30开盘价格模拟成交；收盘日线不能用于当天开盘前决策。最后一日收盘清仓是预先固定的边界条件。
- 初始资金10万美元，单边费用10bps、滑点5bps；二者作为成交金额扣款，双边计入。另运行1.5×、2×成本压力，SPY基准同样计入买入/末尾卖出成本。无融资、杠杆或裸卖空。
- 使用厂商 `adjust=all` 的价格单位模拟经济收益；调整后价格/单位不是当时券商原始股价/实际股数。当前调整版本不能证明历史来源版本，基本面、事件、财报黑窗、实时价差和盘中流动性没有纳入。

## 输出与查询

`runs/<run_id>/report.md`给出候选、现金比例、基准比较和成本压力；`report.json`保留完整分段指标、日净值、模拟成交、配置与数据指纹。`trades.csv`及 `equity.csv`便于后续核对。交易账本现金与成本一致性有独立回归验证。卖出成交腿的利润因子不是独立完整交易的统计；年化用252交易日，Sharpe假设无风险利率为0。

认证后 `GET /research/price-only/latest`可查询最近一次完整研究。如果当前刷新正在采集或失败，则返回collecting/blocked并清空当前候选，不把旧结果重新发布为当前信号。报告缺失为awaiting_real_data，字节/报告指纹异常为503。

输出始终 `execution_allowed=false`，生产验收 `passed=false`。完成真实研究意味着取得上述个人来源完整数据、生成真实候选与真实历史价格模拟账本；离线合成测试、官方demo及生产库里的旧Mock快照均不能替代这一验收。收益为负或不优于基准时如实保留，不能降低门槛、重选股票或调参凑收益。
